# InternHub — платформа для поиска IT-стажировок

**Контрольная работа №2.** Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

**Студент:** Гасанов Джабраил Рамазанович.

## О проекте

InternHub — учебный многостраничный сайт для поиска стажировок и стартовых IT-вакансий. Аналог по пользовательскому сценарию — HeadHunter. Все компании, вакансии и зарплаты в демонстрационном каталоге вымышлены; формы не отправляют данные реальным работодателям.

## Практическая №9

- Подключены Bootstrap 5.3.8 через CDN и собственный `css/custom.css`.
- Созданы адаптивные навигация, hero-блок с поиском, блок преимуществ, сетка популярных стажировок, направления IT и подвал.
- Используются `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*`, `g-*` и вспомогательные классы Bootstrap.
- Добавлено собственное визуальное оформление без замены Bootstrap-сетки.

## План страниц

- `index.html` — главная страница (практическая №9).
- `catalog.html` — каталог с фильтрами (практическая №10).
- `vacancy.html` — описание вакансии и форма отклика (практическая №10).
- `contacts.html` — контакты, обратная связь, FAQ (практическая №10).

На этапе №9 ссылки на ещё не созданные страницы начнут работать после практической №10.
