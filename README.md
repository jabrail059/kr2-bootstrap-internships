## Описание

FastJob — многостраничный сайт для поиска стажировок и стартовых вакансий в IT. В основу пользовательского сценария положена структура поиска на hh.ru: поисковая строка, фильтры, список карточек, подробная страница вакансии и форма отклика.

**Важно:** все вакансии являются статическими данными интерфейса. Backend к формам не подключён. При отправке формы выполняется браузерная проверка полей и показывается честное информационное сообщение; данные не отправляются работодателю или на сервер.

## Страницы

- `index.html` — главная страница: навигация, поиск, популярные вакансии, направления IT и преимущества.
- `catalog.html` — каталог с поиском, фильтрами по направлению / зарплате / формату и сортировкой.
- `vacancy.html?id=...` — полная информация о выбранной вакансии и форма отклика.
- `contacts.html` — контакты, форма обратной связи, FAQ.

## Особенности реализации

Bootstrap — основной CSS-фреймворк, `custom.css` подключается после него. Внешний вид сознательно сделан сдержанным: белые блоки, тонкие границы, компактные вакансии и красный акцент. Сайт не копирует логотип или тексты hh.ru.

Функциональность поиска, фильтров, сортировки и просмотра вакансий работает на локальном массиве данных `js/app.js` без backend. Форма отклика не делает фиктивных обещаний об отправке резюме.
